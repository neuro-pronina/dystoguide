# ДистоГид

Минимальный MVP веб‑сервиса для объективизации позы головы и тремора при шейной дистонии. Интерфейс — Streamlit, обработка кадров — OpenFace 2.0. Пользователь загружает видео, сервис оценивает средние углы головы (pitch/roll/yaw), выделяет вовлечённые оси, ориентировочную тяжесть, формирует отчёты PDF/JSON и предоставляет базовый анализ тремора.

## Системные требования
* Python 3.11
* OpenFace 2.0 (`FeatureExtraction`)
* FFmpeg

## Запуск через Docker (предпочтительно)
1. Подготовьте OpenFace: образ собирает его из исходников. При желании можно примонтировать уже собранный бинарь и указать переменную `OPENFACE_CMD`.
2. Сборка и запуск:
   ```bash
   docker compose up --build
   ```
3. Откройте [http://localhost:8501](http://localhost:8501).

## Запуск локально (без Docker)
1. Установите системные зависимости OpenFace и FFmpeg.
2. Скачайте или соберите OpenFace 2.0 и укажите путь к `FeatureExtraction` через переменную `OPENFACE_CMD`, например:
   ```bash
   export OPENFACE_CMD=/OpenFace/build/bin/FeatureExtraction
   ```
3. Установите Python‑зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   streamlit run app.py
   ```
5. Откройте [http://localhost:8501](http://localhost:8501).

### Как записать видео
* Снимайте фронтально, голова целиком в кадре.
* Глаза закрыты ~10 секунд.
* Нормальное освещение, без резких бликов.
* Камера неподвижна (штатив/стойка).

## Подготовка OpenFace 2.0
В Dockerfile идёт сборка из исходников. Если это слишком долго:
1. Соберите OpenFace заранее и примонтируйте бинарь `FeatureExtraction` в контейнер.
2. Либо укажите путь к имеющемуся бинарю через `OPENFACE_CMD`.

## Ограничения и дисклеймер
* «лёгкая/умеренная/тяжёлая» — простая эвристика по градусам; **не** заменяет шкалы TWSTRS‑2/GDRS и клиническое решение.
* Инструмент не является средством диагностики, предназначен для исследовательских и учебных целей.

## Приватность и хранение
Видео и отчёты хранятся локально в папке `data/`. Автоочистка не реализована; пользователь отвечает за управление файлами.
